# MS SQL Server Bootcamp

A structured 9-day repository of T-SQL practice scripts, exercises, and notes covering relational database design, querying, and database administration in Microsoft SQL Server 2022.

## Repository Structure

```text
ms-sql-server-bootcamp/
├── day-01-keys-and-db-creation/         # Database creation, Primary Key, Unique Key
├── day-02-fk-constraints-design/        # Foreign Keys, ON DELETE/UPDATE, constraints, DB design
├── day-03-dml-select-case/              # INSERT, UPDATE, DELETE, SELECT, expressions, CASE
├── day-04-itworkshop-orderby-scalar/    # IT workshop, ORDER BY, scalar functions
├── day-05-aggregates-groupby-joins/     # Aggregate functions, GROUP BY, HAVING, joins
├── day-06-multijoin-selfjoin-union/     # Multi-table joins, self joins, UNION / UNION ALL
├── day-07-subqueries-cte-views-sp/      # Subqueries, CTEs, views, stored procedures
├── day-08-functions-transactions-identity/ # User-defined functions, transactions, IDENTITY
├── day-09-triggers-admin/               # Triggers and basic SQL Server administration
├── .gitignore
└── README.md
